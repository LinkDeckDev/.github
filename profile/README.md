## About LinkDeck

LinkDeck is an independent hardware project exploring a more physical and expressive way to share digital identity.

The current prototype direction combines:

- a compact AMOLED touchscreen
- NFC/contactless interaction
- QR-based sharing
- swipe and touch navigation
- profile-based digital identity
- a small, portable enclosure designed around real hardware constraints

The project is currently in the **prototype stage**.

## Current focus

We are working on the foundations required for the first complete physical prototype:

- mechanical validation
- enclosure fit and finish
- display and touch bring-up
- NFC integration
- USB-powered firmware development
- power measurements before battery selection
- early UI and interaction design

## Build in public

LinkDeck is being developed openly where it makes sense.

We plan to share:

- prototype progress
- development logs
- UI experiments
- hardware milestones
- lessons learned
- public examples
- selected technical documentation

Some parts of the project will remain private during development, including production CAD, complete firmware, manufacturing data, supplier-sensitive information and provisioning/security details.

## Ray

**Ray** is the LinkDeck mascot — a small technology-inspired manta ray representing connectivity, movement and wireless sharing.

The standard LinkDeck identity uses a dark graphite base with cyan and electric-blue accents.

A red **Special Edition** identity is planned for a future product variant.

## Road to launch

The current path is:

**Prototype → Functional validation → Product refinement → Pre-production → Launch preparation**

A crowdfunding campaign, including a possible **Kickstarter launch**, will only be considered after the hardware and user experience have been validated.

## Status

> LinkDeck is under active development. Hardware, software, specifications and product direction may change before release.
